Problèmes connus

Les animations ne s'affichent pas (surtout sur Firefox)

Le site respecte le réglage « réduire les animations » de ton système : quand il est activé, les animations (tirage du boss, tirage des cosmétiques, effets des pages) sont remplacées par un affichage direct. Firefox suit ce réglage plus strictement que les autres navigateurs, d'où le problème surtout sur Firefox.

Pour retrouver les animations, réactive-les dans ton système, puis recharge la page :

  • Windows 11 : Paramètres → Accessibilité → Effets visuels → active Effets d'animation.
  • Windows 10 : Paramètres → Options d'ergonomie → Affichage → active Afficher les animations dans Windows.
  • macOS : Réglages Système → Accessibilité → Affichage → désactive Réduire les animations.
  • Linux (GNOME, Ubuntu) : Paramètres → Accessibilité → active Animations (ou désactive Réduire les animations).
  • Android : Paramètres → Accessibilité → désactive Supprimer les animations.
  • iPhone : Réglages → Accessibilité → Mouvement → désactive Réduire les animations.

Seulement pour Firefox, sans toucher au réglage du système : tape about:config dans la barre d'adresse, accepte l'avertissement, cherche ui.prefersReducedMotion, crée-le en Nombre s'il n'existe pas, mets-le à 0, puis recharge la page.

Le tirage du boss est une vidéo avec du son : si Firefox est réglé pour bloquer l'audio et la vidéo en lecture automatique, autorise-la pour le site (cadenas à gauche de l'adresse → Lecture automatique → Autoriser l'audio et la vidéo).

Kokomi mal détectée par la détection automatique de box

La détection automatique lit, sur ta capture Hoyolab, la zone à droite du portrait de chaque personnage : son nom et son niveau. Le nom « Sangonomiya Kokomi » est le seul trop long pour son cadre : il déborde sur la gauche (le « S » touche le bord de la zone lue, et il est coupé sur les écrans plus étroits) et il tient sur deux lignes, ce qui pousse son niveau tout en bas de la zone, où il est coupé.

Kokomi est donc toujours signalée à vérifier après la détection : contrôle sa constellation et son niveau à la main avant d'enregistrer ta box.
